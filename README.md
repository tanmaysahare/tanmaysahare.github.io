# tanmaysahare.me

Personal website of **Tanmay Sahare**, founder of [VarshaKrishi](https://www.varshakrishi.com) (satellite crop advice for Indian smallholder farmers, delivered weekly in the farmer's language on WhatsApp), B.Tech Aerospace Engineering student at IIT Kanpur and EiR Fellow, 5G/6G Centre of Excellence, FIRST, IIT Kanpur.

Static site (HTML/CSS/vanilla JS) served via GitHub Pages at [tanmaysahare.me](https://tanmaysahare.me).

- `index.html`: single-page portfolio (Person/Organization JSON-LD, OG/Twitter meta)
- `robots.txt`, `sitemap.xml`, `llms.txt`: SEO and AI discoverability
- `assets/`: profile photo, resume
- `tweettracker/`: TweetTracker project verification page

Wording rules: the company story and the banned-phrase list live in the workspace `plans/GROUND-RULES.md`; the fellowship wording is the only affiliation to use.
